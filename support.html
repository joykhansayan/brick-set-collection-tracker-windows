Adding sets and minifigs

Open Collection and click Add Set, or Minifigs → Add Minifig. Type or paste the set number or barcode into Set Number (use Enter code for a quick code-first entry). Click Choose Photo to attach a picture from your PC.

Filtering and sorting

Use the Owned / Wishlist switch, the status and theme filters, the search box and the sort menu at the top of Collection. Switch between list and grid with the layout button.

Export

Settings → Export Collection saves your collection as a CSV spreadsheet or a printable PDF inventory, handy for insurance.

Restore purchases

If you already subscribed, open the paywall or go to Settings → Restore Purchases. Make sure you are signed in to the Microsoft Store with the same Microsoft account used for the purchase.

Manage or cancel a subscription

Visit account.microsoft.com/services, sign in, and choose Brick Set Collection Tracker under Services & subscriptions.
